  Что означают DENY, ASK, ALLOW, CONDITIONAL и UNKNOWN?
  
DENY — запрещено. ASK — запрос ИИ требует согласования владельца. ALLOW — базовое разрешение без отдельного согласования каждого запроса; прочие проверки операции сохраняются.

  
CONDITIONAL — решение зависит от дополнительных программных условий; это не переключатель ALLOW/ASK/DENY. UNKNOWN — итог для конкретного target не вычислен. UNVERIFIED — внешняя готовность не доказана инвентаризацией.
